# FAQ Assistant

## Project Description

FAQ Assistant is a web-based Frequently Asked Questions system.

It allows users to search for frequently asked questions and receive
answers from stored FAQ data.

The project is developed using Node.js, Express.js and MongoDB.

---

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- dotenv

---

## Main Features

1. Search frequently asked questions
2. Category-based FAQ filtering
3. Add new FAQ
4. Store FAQ data in MongoDB
5. Display answers to users
6. Display category information
7. Display a message when an answer is not found
